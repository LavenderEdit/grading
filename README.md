## Resumen ejecutivo

* REST API construida con Spring Boot 3.5.6 y Java 21 para gestionar plantillas de actividades, asignaciones, usuarios, roles y el historial de puntajes semanales del equipo. [POM](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml), [GradingApplication](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/GradingApplication.java)
* Persistencia con JPA y MySQL, auditorías automáticas vía una entidad base compartida, y migraciones de base de datos con Flyway. [POM](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml), [BaseEntity](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/audit/BaseEntity.java), [JpaConfig](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/JpaConfig.java)
* Autenticación/autorización JWT con filtros stateless; todos los endpoints están protegidos salvo login y registro. [SecurityConfig](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/SecurityConfig.java), [JwtTokenProvider](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtTokenProvider.java), [JwtAuthenticationFilter](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtAuthenticationFilter.java), [AuthController](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/controller/AuthController.java)
* Modelo de dominio que cubre usuarios, roles, plantillas de actividades, sets, asignaciones e historial de puntajes, expuesto mediante DTOs MapStruct. [User](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/model/User.java), [Role](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/model/Role.java), [ActivityTemplate](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/model/ActivityTemplate.java), [ActivitySet](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/model/ActivitySet.java), [Assignment](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/model/Assignment.java), [ScoreHistory](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/model/ScoreHistory.java), [UserMapper](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/mapper/UserMapper.java)
* Respuesta consistente mediante `ApiResponse` y manejo centralizado de errores con códigos HTTP claros. [ApiResponse](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/response/ApiResponse.java), [GlobalExceptionHandler](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/exception/GlobalExceptionHandler.java)

## Visión general

El servicio orquesta plantillas de actividades semanales, las asigna a colaboradores, registra entregas y ajusta puntajes de desempeño. Usa starters de Spring Boot para web, seguridad, validación y JPA; JJWT para tokens; SpringDoc para OpenAPI; Flyway para migraciones; y Lombok/MapStruct para reducir boilerplate. [F: pom.xml L40–L124](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml#L40-L124) · [F: GradingApplication.java L14–L24](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/GradingApplication.java#L14-L24)

## Seguridad

La aplicación aplica seguridad JWT sin estado:

* `SecurityFilterChain` deshabilita CSRF, fija sesiones como stateless, lista blanca `/api/auth/**` y `/actuator/**`, y protege el resto de endpoints. [F: SecurityConfig.java L49–L63](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/SecurityConfig.java#L49-L63)
* Contraseñas hasheadas con `BCryptPasswordEncoder` de fuerza 12; autenticación delegada a un proveedor DAO usando `UserDetailsService` personalizado. [F: SecurityConfig.java L28–L41](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/SecurityConfig.java#L28-L41) · [F: UserServiceImpl.java L197–L213](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/service/impl/UserServiceImpl.java#L197-L213)
* JWTs firmados con HS256, incluyen `issuer` y expiración configurables, y el filtro extrae tokens Bearer por request para poblar el contexto de seguridad. [F: JwtTokenProvider.java L31–L77](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtTokenProvider.java#L31-L77) · [F: JwtAuthenticationFilter.java L25–L60](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtAuthenticationFilter.java#L25-L60) · [F: JwtProperties.java L9–L13](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtProperties.java#L9-L13)
* Login/registro devuelven `AuthResponse` con token, tipo y expiración; credenciales validadas vía `AuthenticationManager`. [F: AuthController.java L28–L37](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/controller/AuthController.java#L28-L37) · [F: AuthServiceImpl.java L25–L50](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/service/impl/AuthServiceImpl.java#L25-L50)
* `RestAuthenticationEntryPoint` garantiza un `401` JSON para accesos no autorizados, complementando la estrategia de excepciones global. [F: RestAuthenticationEntryPoint.java L19–L33](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/RestAuthenticationEntryPoint.java#L19-L33) · [F: GlobalExceptionHandler.java L24–L64](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/exception/GlobalExceptionHandler.java#L24-L64)

## Errores y contratos

Las respuestas siempre usan el sobre `ApiResponse`. Las excepciones de dominio (usuarios/roles inexistentes, credenciales inválidas, conflictos) son interceptadas por `GlobalExceptionHandler`, devolviendo códigos precisos (`404`, `401`, `400`, `409`, `500`) y timestamps. [F: ApiResponse.java L6–L56](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/response/ApiResponse.java#L6-L56) · [F: GlobalExceptionHandler.java L14–L65](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/exception/GlobalExceptionHandler.java#L14-L65)

## Puesta en marcha

1. **Prerrequisitos**

   * JDK 21 y Maven Wrapper (`mvnw`) incluidos en el repo. [F: pom.xml L29–L35](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml#L29-L35) · [F: mvnw (cabecera)](https://github.com/LavenderEdit/grading/blob/lavender/mvnw#L1-L40)
   * Base MySQL accesible usando el patrón de URL en `spring.datasource.url`; Flyway aplicará migraciones cuando existan. [F: application.properties L6–L19](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L6-L19)

2. **Configura variables de entorno**

   * Provee credenciales de DB y secretos JWT (`MYSQL_HOST`, `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`, `JWT_SECRET`, `JWT_EXPIRATION_MINUTES`). [F: application.properties L16–L24](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L16-L24)

3. **Ejecuta la aplicación**

   ```bash
   ./mvnw spring-boot:run
   ```

   Elige el perfil con `-Dspring.profiles.active=dev` o `prod` según necesidad. [F: application-dev.properties L3–L5](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application-dev.properties#L3-L5) · [F: application-prod.properties L3–L9](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application-prod.properties#L3-L9)

4. **Empaqueta el jar ejecutable (opcional)**

   ```bash
   ./mvnw clean package
   ```
