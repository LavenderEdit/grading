[Versión en español disponible aquí](README.md).

## Executive summary

* REST API built with Spring Boot 3.5.6 and Java 21 to manage activity templates, assignments, users, roles, and weekly score history for the team. [POM](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml), [GradingApplication](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/GradingApplication.java)

[POM](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml), [BaseEntity](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/audit/BaseEntity.java), [JpaConfig](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/JpaConfig.java)

## Overview

The service orchestrates weekly activity templates, assigns them to collaborators, records submissions, and adjusts performance scores. It leverages Spring Boot starters for web, security, validation, and JPA, combines the JJWT stack for tokens, SpringDoc for OpenAPI, Flyway for migrations, and Lombok/MapStruct to reduce boilerplate. [F: pom.xml L40–L124](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml#L40-L124) · [F: GradingApplication.java L14–L24](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/GradingApplication.java#L14-L24)

## Security

The application enforces stateless JWT security:

* `SecurityFilterChain` disables CSRF, sets sessions to stateless, whitelists `/api/auth/**` and `/actuator/**`, and protects every other endpoint. [F: SecurityConfig.java L49–L63](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/SecurityConfig.java#L49-L63)
* Passwords are hashed with a strength-12 `BCryptPasswordEncoder`, and authentication is delegated to a DAO provider using the custom `UserDetailsService`. [F: SecurityConfig.java L28–L41](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/config/SecurityConfig.java#L28-L41) · [F: UserServiceImpl.java L197–L213](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/service/impl/UserServiceImpl.java#L197-L213)
* JWTs are signed with HS256, include configurable issuer and expiration, and the filter extracts Bearer tokens per request to populate the security context. [F: JwtTokenProvider.java L31–L77](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtTokenProvider.java#L31-L77) · [F: JwtAuthenticationFilter.java L25–L60](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtAuthenticationFilter.java#L25-L60) · [F: JwtProperties.java L9–L13](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/JwtProperties.java#L9-L13)
* Login/registration returns an `AuthResponse` with token, type, and expiration; credentials are validated through the `AuthenticationManager`. [F: AuthController.java L28–L37](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/controller/AuthController.java#L28-L37) · [F: AuthServiceImpl.java L25–L50](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/service/impl/AuthServiceImpl.java#L25-L50)
* `RestAuthenticationEntryPoint` ensures a JSON `401` for unauthorized access, complementing the global exception strategy. [F: RestAuthenticationEntryPoint.java L19–L33](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/util/security/RestAuthenticationEntryPoint.java#L19-L33) · [F: GlobalExceptionHandler.java L24–L64](https://github.com/LavenderEdit/grading/blob/lavender/src/main/java/com/grade/manage/exception/GlobalExceptionHandler.java#L24-L64)

* External variables (`MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`, `JWT_SECRET`, `JWT_EXPIRATION_MINUTES`) fill database and JWT configuration placeholders. [F: application.properties L16–L24](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L16-L24)
* Flyway is enabled, SQL formatting is turned on, and only `health`/`info` actuator endpoints are exposed. [F: application.properties L6–L14](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L6-L14) · [F: application.properties L27–L28](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L27-L28)
* `dev` profile increases Hibernate/web logs; `prod` profile tweaks logging levels and HikariCP pool size. [F: application-dev.properties L3–L5](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application-dev.properties#L3-L5) · [F: application-prod.properties L3–L9](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application-prod.properties#L3-L9)

## Error handling and contracts

Responses always use the `ApiResponse` envelope. Domain exceptions (missing users/roles, invalid credentials, conflicts) are intercepted by `GlobalExceptionHandler`, returning accurate status codes (`404`, `401`, `400`, `409`, `500`) and timestamps. ## Getting started

1. **Prerequisites**

   * JDK 21 and the Maven Wrapper (`mvnw`) included in the repository. [F: pom.xml L29–L35](https://github.com/LavenderEdit/grading/blob/lavender/pom.xml#L29-L35) · [F: mvnw (script head)](https://github.com/LavenderEdit/grading/blob/lavender/mvnw#L1-L40)
   * Reachable MySQL database using the URL pattern defined in `spring.datasource.url`; Flyway will apply migrations when present. [F: application.properties L6–L19](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L6-L19)

2. **Configure environment variables**

   * Provide database credentials and JWT secrets (`MYSQL_HOST`, `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`, `JWT_SECRET`, `JWT_EXPIRATION_MINUTES`). [F: application.properties L16–L24](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application.properties#L16-L24)

3. **Run the application**

   ```bash
   ./mvnw spring-boot:run
   ```

   Choose the profile with `-Dspring.profiles.active=dev` or `prod` according to your needs. [F: application-dev.properties L3–L5](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application-dev.properties#L3-L5) · [F: application-prod.properties L3–L9](https://github.com/LavenderEdit/grading/blob/lavender/src/main/resources/application-prod.properties#L3-L9)

4. **Build the executable jar (optional)**

   ```bash
   ./mvnw clean package
   ```
